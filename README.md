# 拾音岛 · Isle of Songs

> 靠近一个人，他的歌会慢慢变得清晰。

一座漂在暖色云海里的大岛。没有任务，没有排行榜，没有需要完成的任何事——只有音乐，和同样在听歌的人。

带上耳机，选一首歌，落进世界吧。

## 这是什么

拾音岛是一个只为舒服听歌而存在的世界。

每个人入场时都带着一首正在播放的歌。远远望去，别人身边浮动着一圈微光，随着他们的音乐轻轻起伏——那是歌的形状。当你走近，笼罩在旋律外的那层朦胧会一寸寸散开，像雾里传来的歌声，渐渐透亮，直到你站在他身旁，和他听见同一个世界。

不说话也没关系。在这里，靠近就是问候，共听就是陪伴；转身离开，歌声便温柔地淡回风里。

## 拾音岛

一整座可以自由漫游的大岛，从海岸到山顶，走着就能到达：

- **篝火广场** —— 岛的中心。暖金色的火光下，路过的人把歌留在这里，围坐成一圈，各自安静。
- **花田草坡** —— 向阳的缓坡，风把远处的旋律吹得很淡。适合躺下，只听自己的歌。
- **白色沙岸** —— 沿着海走，浪声垫在所有人的歌底下。傍晚整条海岸线会被染成蜜色。
- **灯塔山丘** —— 岛的最高处。云海在脚下，暮色从粉紫褪成深蓝，是全岛最安静的地方。

白昼与黄昏缓缓轮转，光落在每个人身上都是软的。

## 怎么玩

- **移动** —— `W A S D` 或方向键
- **视角** —— 移动鼠标环顾四周
- **坐下** —— `E`，在篝火边、在沙滩上、在任何地方
- **听** —— 不需要任何操作

走近一个人，他的歌自然清晰起来；走远，便自然淡去。世界永远只让你清晰听见身边最近的两三首歌，其余的都化进环境里——所以无论多少人同时在听，岛上始终是安静的。

## 常见问题

**需要下载或安装吗？**
不需要。用现代浏览器（推荐最新版 Chrome / Edge / Safari）打开链接即可进入。

**我听的歌，别人能听到吗？**
只有走到你身边的人才听得见，并且一切随距离淡去。你的歌只属于靠近你的人。

**很多人一起听歌，会不会很吵？**
不会。距离和耳朵会替你做好混音，远处的歌只是风里模糊的一点甜。

**需要注册账号吗？**
起一个名字就够了。

## 技术构成

纯浏览器运行，无需插件，整座世界由以下部分搭成：

| 模块 | 技术 | 职责 |
|---|---|---|
| 世界渲染 | Three.js + Vite | 岛屿场景；雾、渐变天空、bloom 后期、toon 光影，构成柔和的画面基调 |
| 界面层 | 原生 DOM 覆盖层 | 播放控件、歌单、设置，浮在画布之上 |
| 声音 | Web Audio API | 距离衰减 + 低通滤波实现"靠近变清晰"；本地混音，最多同时清晰 3 路 |
| 实时同步 | Colyseus（Node.js · TypeScript · WebSocket） | 单房间大岛 + 按距离的兴趣管理（AOI），只同步身边玩家的位置与播放状态 |
| 音源 | 曲库同步播放 | 各端本地播放同一曲目，服务器只同步曲目与进度，音频流不经过服务器 |
| 部署 | 前端 EdgeOne Pages · 实时服务自托管 | 打开链接即进入世界 |

## 关于名字

「拾音」：走在岛上，一路把别人的歌声拾起来——每一次靠近，都捡到一首歌；转身离开，歌声又轻轻放回风里。
